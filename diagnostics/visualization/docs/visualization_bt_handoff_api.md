# Visualization Input / Output Contract

**用途**：说明 Visualization MVP 需要什么预报数据、会生成什么文件。  
**版本**：2026-10-09。

## 输入数据及描述信息（Input contract）

每次接收一套已选定的预报结果，绘制其中一个变量，例如雷达反射率。输入包含这个变量在多个预报时刻的数值；只有一个时刻也可以。

每个时刻是一张二维数值表：`y` 对应行，`x` 对应列。把多个时刻依次排列，就得到一个三维数组，其大小写作 **预报时效数量 × 网格行数 × 网格列数**。例如，`(20, 128, 128)` 表示 20 个预报时刻，每个时刻有 128 行、128 列。

下面列出需要提供的信息。实际存储顺序可以不同，但必须说明哪个维度是时间、行和列。

### 必需信息

| 信息 | 需要提供什么 |
|---|---|
| 预报数值 |  **预报时效数量 × 网格行数 × 网格列数**。例如，`(20, 128, 128)` 表示 20 个预报时刻，每个时刻有 128 行、128 列，可以是整数或小数。至少有 1 个预报时刻，每个时刻至少有 2 行、2 列；所有时刻的行数、列数和格点位置一致。时刻数量和网格大小不固定 |
| 变量名称 | 说明数值表示什么，例如“雷达反射率” |
| 数值单位 | 说明数组中数值的单位，例如反射率用 dBZ、降水强度用 mm/h。输入数值应已转换到所声明的单位，可以直接按该单位解释 |
| 格点坐标 | 提供每一列的 x 坐标、每一行的 y 坐标及坐标单位。x 坐标数量等于列数，y 坐标数量等于行数；坐标表示格子中心的位置。经纬度网格中，x 是经度，y 是纬度 |
| 网格排列 | 相邻列的 x 坐标间隔固定，相邻行的 y 坐标间隔固定；两种间隔可以不同。每组坐标可从小到大或从大到小排列，但不能重复或中途反向，也不能缺失或为无穷值 |
| 坐标系（CRS） | 提供格点坐标所用坐标系的标准编号。例如 `EPSG:4326` 表示 WGS 84 经纬度坐标系，坐标单位为“度”。当前也支持 UTM 网格（按地区分区、以“米”表示位置的平面坐标网格）；使用时提供该分区对应的具体坐标系编号 |
| 起报时间（init time） | 这次预报的基准时间，所有预报时效从它开始计算。必须注明时区，例如 `2026-10-09 00:00 UTC`；UTC 是协调世界时 |
| 预报时效（lead time） | 每张网格距离起报时间多久，例如 `[5, 10, 15] 分钟`。需写明时间单位，按从小到大排列；允许 0，不允许负数或重复，间隔可以不同 |
| 预报值的时间含义 | 说明数值是某一时刻的值、某段时间的累计值，还是某段时间的平均值。累计值和平均值还需提供每张网格的统计开始、结束时间；开始早于结束，结束时间等于“起报时间 + 该帧预报时效” |
| 缺测表示 | 没有有效数据的位置统一写为 `NaN`（缺失数值标记），不能用 0 代替；真实的 0 值保留。每张网格至少有一个有效数值 |

### 可选信息

| 信息 | 用途 |
|---|---|
| 预报对应时间（valid time） | 每张网格对应的实际日期和时间。可由“起报时间 + 预报时效”计算，因此可以省略；若提供，必须与计算结果一致 |
| 数据来源 | 可提供这次运行的编号、模型或数据产品的名称与版本等，便于辨认结果来自哪里。提供的信息会随输出记录，未提供的内容不推测补齐 |

本轮绘图无需提供对照实况或评分结果；底图和图像样式由 Visualization 侧准备。

### 小例子：2 个时刻、2 行、3 列

以下为说明用例，实际数据的大小、坐标、时间和数值可以不同：

```text
变量：雷达反射率
单位：dBZ
坐标系：WGS 84 经纬度（EPSG:4326），坐标单位为度
起报时间：2026-10-09 00:00 UTC
预报时效：[5, 10] 分钟
预报值的时间含义：瞬时值
每列经度 x：[110.0, 110.1, 110.2]
每行纬度 y：[30.1, 30.0]

起报后 5 分钟的数值：
[[10, 20, 30],
 [ 0, NaN, 40]]

起报后 10 分钟的数值：
[[15, 25, 35],
 [ 0,  5, 45]]
```

这组数据的数组大小为 `(2, 2, 3)`，对应的预报时间是当天 00:05 和 00:10 UTC。第一个时刻的第一行第二列是 `20 dBZ`，位置为东经 `110.1°`、北纬 `30.1°`。

## 输出文件及描述信息（Output contract）

每组输入生成下列文件，保存目录在接入时指定。文件名为默认名称。

| 文件 | 内容 |
|---|---|
| `map.png` | 第一张预报网格的地图图片，标明变量、单位、起报时间和对应的预报时间，并包含颜色刻度和底图来源说明 |
| `animation.gif` | 按预报时间先后播放的动画，每个时效对应一帧，并标明该帧时间。整段动画使用相同的地图范围、底图和颜色刻度；播放快慢不改变标注的预报时间 |
| `manifest.json` | Visualization 输出产物说明：一份 JSON 文字清单，记录图片文件的位置、所绘变量、单位、空间范围和时间，以及用于检查文件是否变化的校验值 |

还可按需为每个预报时效另存一张 PNG 图片。
