Verification configs

One config fixes three things: the ruler (what is compared, on which grid, at what step), the roster (which members, over which dates), and the metrics. The ruler cannot be edited — a change to it needs a new config, because the numbers before and after would not be comparable.

4Metrics

Three families, all added for you. Everything in a family shares its parameters and is accumulated in the same pass, so there is nothing to pick — only the parameters to fill in, and a family to drop if you do not want it. Levels and windows are parameters, not metrics: a new threshold adds rows, a new metric does not.

Query
